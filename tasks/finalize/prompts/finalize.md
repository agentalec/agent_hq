# Finalize prompt

Write `specs/{ticket}/summary.md` — the closing summary posted to the ticket
thread when the ticket completes.

Summarize what was actually done for this ticket. Read whatever artifacts were
handed to you (see Available inputs below) and reflect them:
- `specs/{ticket}/spec.md` — what was asked; note which acceptance criteria
  are met.
- `specs/{ticket}/review.md` — if present, state the final review outcome and
  call out any `should-fix`/`nit` items left for the human reviewer.

Keep it short and factual — a few sentences plus a bullet list. Do not
implement anything; this task only writes the summary.
